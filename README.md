# Educational-HTML-Game
ReadMe Included


This is an educational Web Browser game designed to increase and improve Computer Science Students' confidence in tackling JavaScript errors. This program will teach students how to prevent infinite loops, utilize proper syntax, and ensure safety nets when writing their code. This game was mainly built in collaboration with Claude Opus 4.8, as part of assisting a Colorado School of Mines professor in their PhD research. For myself, this project was a learning tool as an introduction to JavaScript, more advanced HTML and CSS techniques, and proper heavy duty AI Agent prompting. 

index.html - the main web file. Run this through your browser if you'd like to play the game! \
game.js - JavaScript file for various game functions and website functionality. \
questions.html - as part of the PhD research, this file takes you to a website where you can test what you've learned from the video game through a quick 10 question quiz. \
answers.md - the answer key to questions.html
